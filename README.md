# ScenarioForge

## Digital Business Scenario Engine

**ScenarioForge** هو تطبيق ويب تفاعلي مبني باستخدام Python وStreamlit، صُمم لمساعدة أصحاب المشاريع الصغيرة ومديري الأعمال على فهم أثر القرارات التشغيلية والمالية قبل تنفيذها. يتيح التطبيق إدخال بيانات النشاط الحالية، ثم اختبار تغييرات افتراضية في السعر والتكلفة وحجم المبيعات والتكاليف الثابتة، مع عرض النتائج فورًا عبر مؤشرات ورسوم بيانية تفاعلية.

> يساعد التطبيق في **تقليل المخاطر المالية عبر المحاكاة الرقمية**، لأنه يحول سؤال «ماذا لو؟» إلى سيناريو قابل للقياس والمقارنة قبل اتخاذ القرار.

## لماذا يخدم التحول الرقمي للمشاريع الصغيرة؟

لا يقتصر التحول الرقمي على نقل العمليات الورقية إلى أدوات إلكترونية؛ بل يشمل بناء قدرة مستمرة على استخدام البيانات في التخطيط واتخاذ القرار. يقدم ScenarioForge نموذجًا عمليًا لهذه القدرة من خلال تجميع المدخلات المالية الأساسية في واجهة واحدة، وربطها بمحرك حسابات شفاف، ثم تحويلها إلى مؤشرات مفهومة بصريًا.

بدل الاعتماد على الحدس عند رفع الأسعار أو توسيع الفريق أو تغيير الموردين، يستطيع صاحب المشروع اختبار عدة افتراضات خلال ثوانٍ. وهذا يرفع جودة الحوار الإداري، ويساعد على اكتشاف نقطة التعادل، وفهم هامش المساهمة، وتقدير حساسية الربحية لتغيرات السوق والتكلفة.

## المزايا الرئيسية

| الميزة | القيمة العملية |
| --- | --- |
| لوحة إدخال بيانات | إدخال التكاليف الثابتة، والتكلفة المتغيرة للوحدة، وسعر البيع، وحجم المبيعات الشهري. |
| شرائح السيناريوهات | محاكاة التغير النسبي في السعر والتكاليف وحجم المبيعات دون تعديل بيانات خط الأساس. |
| مؤشرات الأداء | عرض الربح المتوقع، والإيرادات، وهامش المساهمة، ونقطة التعادل. |
| المقارنة البصرية | مقارنة مباشرة بين الوضع الحالي والسيناريو المقترح باستخدام مخطط أعمدة. |
| منحنى الربحية | إظهار تغير الربح مع زيادة الوحدات المباعة، مع خط الصفر لتوضيح منطقة الخسارة والربح. |
| حاسبة نقطة التعادل | تحديد عدد الوحدات اللازمة لتغطية التكاليف في كل سيناريو. |
| واجهة فاتحة مرتبة | تصميم ملائم للاستخدام المكتبي والجوال مع مؤشرات واضحة وتدرجات لونية هادئة. |
| اختيار السوق والعملة | اختيار السعودية أو أسواق عربية ودولية أخرى مع عرض النتائج بالعملة المناسبة. |
| تحليل منصة عبر الرابط | قراءة المعلومات العامة للمنصة واستخراج إشارات الخدمات والبحث عن نتائج منافسين مرتبطة بالسوق. |
| تقرير ذكاء اصطناعي متقدم | تلخيص استراتيجي، تحديد الجمهور والقيمة، تحليل القوة والمخاطر، وفرص النمو والتوصيات. |

## المنطق المالي

يستخدم المحرك معادلات تحليل مالي بسيطة وقابلة للمراجعة:

- **الإيرادات** = سعر البيع للوحدة × عدد الوحدات المباعة.
- **إجمالي التكاليف المتغيرة** = التكلفة المتغيرة للوحدة × عدد الوحدات المباعة.
- **الربح التشغيلي التقديري** = الإيرادات − إجمالي التكاليف المتغيرة − التكاليف الثابتة.
- **هامش المساهمة للوحدة** = سعر البيع − التكلفة المتغيرة للوحدة.
- **نقطة التعادل بالوحدات** = التكاليف الثابتة ÷ هامش المساهمة للوحدة.

إذا كان هامش المساهمة مساويًا للصفر أو سالبًا، يعرض التطبيق نقطة التعادل باعتبارها غير ممكنة وفق الافتراضات المدخلة؛ لأن كل وحدة لا تسهم حينها في تغطية التكاليف الثابتة.

## التشغيل محليًا

يتطلب المشروع Python 3.10 أو أحدث. بعد تنزيل المستودع، نفّذ الأوامر التالية من داخل مجلد المشروع:

```bash
git clone https://github.com/abd8008-cloud/scenarioforge.git
cd scenarioforge
python -m venv .venv
source .venv/bin/activate  # على Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
streamlit run app.py
```

بعد تشغيل الأمر الأخير، افتح الرابط المحلي الذي يعرضه Streamlit في المتصفح. التطبيق لا يحتاج إلى قاعدة بيانات أو مفاتيح API؛ فجميع الحسابات تتم لحظيًا داخل الجلسة.

## طريقة الاستخدام

ابدأ باختيار السوق المستهدف من الشريط الجانبي؛ تبدأ القائمة بالسعودية وتضم الإمارات والكويت وقطر والبحرين وعُمان والأردن ومصر والمغرب والولايات المتحدة والمملكة المتحدة والسوق الدولي. بعد ذلك أدخل أرقام الشهر الحالي، وستظهر النتائج بالعملة المرتبطة بالسوق المختار. ثم راجع مؤشرات خط الأساس. بعد ذلك استخدم شرائح السيناريوهات لاختبار مجموعة من الفرضيات، مثل رفع السعر بنسبة 10%، أو خفض تكلفة الوحدة بنسبة 5%، أو زيادة حجم المبيعات بنسبة 15%. ستتحدث المؤشرات والرسوم البيانية تلقائيًا، ويمكن استخدام النتائج كنقطة بداية لمناقشة خطة العمل أو إعداد نموذج مالي أكثر تفصيلًا.

## تسجيل دخول الإدارة

أضيفت طبقة دخول لحماية لوحة المحاكاة. لا تضع كلمة المرور نفسها داخل GitHub، خصوصًا بعد جعل المستودع عامًا. يستخدم التطبيق **PBKDF2-HMAC-SHA256** مع salt عشوائي وعدد تكرارات مرتفع، ويقارن التجزئة باستخدام مقارنة آمنة.

لإنشاء تجزئة لكلمة مرور جديدة محليًا، نفّذ:

```bash
python scripts/generate_password_hash.py YOUR_STRONG_PASSWORD
```

انسخ الناتج، ثم أنشئ ملفًا محليًا باسم `.streamlit/secrets.toml`:

```toml
[admin]
username = "abood808"
password_hash = "ضع_الناتج_هنا"
```

على Streamlit Cloud، افتح إعدادات التطبيق ثم **Settings → Secrets** والصق محتوى ملف الأسرار. ولتفعيل التقرير الذكي أضف `OPENAI_API_KEY` واختر نموذجًا مناسبًا عبر `OPENAI_MODEL` مثل `gpt-4o-mini`. لا تضع مفتاح API داخل GitHub ولا تشاركه في واجهة التطبيق. إذا كنت تستخدم شاشة تحليل المنصة، أضف أيضًا مكتبات `requests` و`beautifulsoup4` الموجودة في `requirements.txt`. لا ترفع ملف `.streamlit/secrets.toml` إلى GitHub؛ الملف الموجود في المستودع هو مثال فقط. استخدم كلمة مرور قوية وفريدة، وغيّرها إذا شاركتها مع أي شخص.

## تحليل المنصة والسوق عبر الإنترنت

تتضمن الواجهة شاشة **تحليل منصة عبر الرابط**. يضع المستخدم رابطًا عامًا ويختار السوق المستهدف، ثم يحاول التطبيق استخراج عنوان الصفحة ووصفها والعناوين/الإشارات الخدمية، ويجري بحثًا عامًا عن نتائج مرتبطة بالمنافسين في السوق المختار. هذه الوظيفة لا تتجاوز الصفحات العامة ولا تحاول تسجيل الدخول أو تجاوز الحماية.

نتائج المنافسين هي **اكتشاف أولي** من نتائج الويب وليست تصنيفًا نهائيًا للسوق. بعد ذلك يمكن الضغط على **إنشاء التقرير الذكي** لتحويل الإشارات إلى تحليل استراتيجي منظم بواسطة النموذج اللغوي. قد تختلف النتائج حسب اللغة والدولة وتوفر الصفحة لمحركات البحث. لا تُدخل روابط خاصة أو بيانات سرية، ولا تعتمد على النتائج وحدها في قرار تجاري.

## حدود النموذج

هذا التطبيق نموذج تخطيط تعليمي وعملي مبسط، ولا يمثل نظامًا محاسبيًا أو توقعًا مضمونًا للمبيعات. اختيار السوق يحدد الدولة والعملة والتنسيق المعروض، لكنه لا يجلب تلقائيًا أسعار السوق أو بيانات المنافسين أو مؤشرات الاقتصاد الكلي؛ هذه الوظائف تحتاج إلى مصدر بيانات خارجي موثوق وربط API مستقل. فهو يفترض ثبات العلاقة بين الوحدات والتكاليف، ولا يتضمن الضرائب أو المخزون أو الموسمية أو القيود النقدية أو تغير الطلب الناتج عن السعر. لذلك ينبغي استخدامه للاستكشاف الأولي، ثم مراجعة النتائج مع محاسب أو مستشار أعمال عند اتخاذ قرارات جوهرية.

## أفكار للتطوير المستقبلي

يمكن توسيع المشروع بإضافة حفظ السيناريوهات وتصدير التقارير إلى CSV أو PDF، وإدخال الموسمية الشهرية، وإضافة تحليل الحساسية متعدد المتغيرات، وربط البيانات الفعلية من نظام نقاط البيع، وتوفير صلاحيات مستخدمين ولوحة تاريخية لقياس الفرق بين التوقع والنتيجة الفعلية.
